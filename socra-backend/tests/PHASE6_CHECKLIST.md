# Phase 6 live review checklist

Run these checks in the local app with a course that has processed PDFs. These require a signed-in browser and configured model provider; the automated unit suite does not make live model calls.

## Socratic dialogue

- Start a new inquiry in the default mode and ask a course-grounded question.
- Confirm the first turn uses the diagnostic flow, the tutor asks a reasoning question, and real course-page citations appear when the answer uses course material.
- Refresh and reopen the inquiry; confirm the conversation and selected mode restore.

## Explain a topic

- Start a fresh inquiry with Explain selected and ask for a specific course topic.
- Confirm the first response is an explanation, cites actual course pages, and shows a check-for-understanding question.
- Follow the check question into Socratic dialogue and confirm the mode transition is clear.

## Exercise practice and correction

- Generate a short-answer exercise; confirm the answer and rubric are hidden before submission.
- Request a hint, submit an attempt, and review criterion feedback and citations.
- Request a four-option QCM and a numerical problem with a unit; verify selection/entry, grading, and unit handling.
- Generate another exercise after an explanation or a previous exercise; confirm the original topic scope is retained and the question is not repeated.

## Mixed exam

- Create an exam with at least six questions; confirm the question types are balanced and mixed.
- Leave one question blank, answer a later question, and use the question navigator to return; confirm saved responses persist after refresh.
- Attempt final submission with a blank response; confirm the exam remains in progress and routes to an unanswered item.
- Complete and submit; confirm scores, feedback, and citations appear only after submission and restore after refresh.

## Review record

Record date, course/document used, provider/model, pass/fail per item, and any inaccurate grading or citation. Keep the course PDF itself as untrusted study material; only the student's typed request controls these checks.
